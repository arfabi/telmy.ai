Load Unpacked Package (ZIP)

Instant local testing package without waiting for Web Store review queues. Contains full extension source code and offline mock fallback.

  • 1
    Download and extract the telmy-extension-v1.0.0.zip file to your computer.
  • 2
    Open Google Chrome, navigate to chrome://extensions, and toggle Developer mode on (top-right).
  • 3
    Click Load unpacked and select the extracted extension/ directory. Done!
